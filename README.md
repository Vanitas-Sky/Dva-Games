# Dva-Games
Repositorio para el proyecto web de plataforma de juegos Dva Games.

## Tecnologías
Este proyecto está basado en **Python/Django**.

## Base de datos
Para el correcto funcionamiento de la aplicación, se ha incluido un respaldo de la base de datos dentro del archivo `.rar` del repositorio. Este respaldo es útil para quienes deseen probar la aplicación localmente.
